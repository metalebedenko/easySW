# Changelog

## v1.0.0

Первая публичная версия EasySW.

- Исправление раскладки выделенного текста по глобальной горячей клавише.
- Исправление слова под кареткой, если выделения нет.
- Фоновая работа в системном трее.
- Настройка одной горячей клавиши.
- Опция запуска вместе с Windows без прав администратора.
- UI Automation как основной путь работы с текстом, с аккуратными fallback-механизмами для обычных Windows-приложений.
- Легковесный нативный Win32 `exe` без тяжелых рантаймов.
